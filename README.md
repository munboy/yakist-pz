## 📁 Структура репозиторію

- **[KNOWLEDGE_GRAPH.md](KNOWLEDGE_GRAPH.md)** — Інтерактивний граф знань, онтологія курсу та миттєвий довідник.
- **`Лабораторные работы/`**
  - **`16+_Методичка 2020.md`** — повний Markdown-конспект офіційної методички ДНУЗТ (2020) до ЛР 1–4.
  - **`Лабораторная работа 1/`** — конспекти та субтитри до ЛР 1 (тестування «Білою скринькою», програма-драйвер).
  - **`Лабораторная работа 2/`** — конспекти та відеоінструкції до ЛР 2 («Чорна скринька», модульне тестування C# та C++ у Visual Studio).
- **`Лекции/`**
  - **`Лекция 1` – `Лекция 7`** — конспекти, слайди та субтитри лекцій (життєвий цикл, тест-плани, тест-кейси, дефекти, багатомодульні програми, автоматизація).
  - **`11.md`** — конспект Лекції 11 (обчислювальна складність алгоритмів $O, \Omega, \Theta$, метод дерева рекурсій, амортизаційний аналіз).
  - **`12.md`** — конспект Лекції 12 (натурні стендові випробування, SRL-показники $S, R, L$).
