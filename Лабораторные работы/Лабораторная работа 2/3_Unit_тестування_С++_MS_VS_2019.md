## 🎯 Синопсис та ключова мета
Практичний відеоурок з налаштування та написання нативних модульних тестів мовою C++ у середовищі Microsoft Visual Studio 2019. Покроково демонструється створення основного проекту C++, виділення логіки в окремі файли/бібліотеки, додавання проекту Native Unit Test, конфігурація каталогу заголовків (Include Directories), макроси `TEST_CLASS`, `TEST_METHOD` та твердження `Assert::AreEqual`.

## ⏱ Детальний структурований конспект за темами та таймлайном
### `[00:00:02 - 00:03:30]` Створення проекту та налаштування рішення
- Створення основного консольного проекту або статичної бібліотеки мовою C++ у Visual Studio 2019.
- Виділення тестованого класу або функції у заголовочний файл (`.h`) та файл реалізації (`.cpp`).
- Додавання нового тестового проекту: `Add -> New Project -> Native Unit Test Project`.

### `[00:03:30 - 00:07:30]` Конфігурація зв'язку між проектами (References & Include)
- Додавання посилання на основний проект: `Add -> Reference`.
- Налаштування додаткових каталогів включення: `Properties -> C/C++ -> General -> Additional Include Directories` (додати шлях до папки з `.h` файлом).
- Підключення заголовка в тестовий файл: `#include "MyClass.h"`.

### `[00:07:30 - 00:11:41]` Написання тестів та запуск у Test Explorer
- Структура тестового файлу: директиви `TEST_CLASS(MyTests)` та `TEST_METHOD(TestMethod1)`.
- Використання методів `Assert::AreEqual(expected, actual)`.
- Вікно `Test Explorer (Обозреватель тестов)`: запуск `Run All Tests`, перегляд зелених/червоних результатів та діагностики помилок.

## 💡 Важливі акценти, правила викладачки та типові помилки
- Головна складність у C++ — правильне прописування Additional Include Directories та лінкування .obj/.lib файлів.
- Тести повинні бути зібрані під ту саму архітектуру (x86 або x64), що й основний проект.
