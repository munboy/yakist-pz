## 🎯 Синопсис та ключова мета
Відеоурок викладачки з розробки автоматизованих модульних тестів (Unit Tests) мовою C# у середовищі Visual Studio. Детально пояснюється сутність юніт-тестування як автоматизованої перевірки окремих методів. Покроково показується створення основного проекту C#, додавання тестового проекту (MSTest), встановлення зв'язку між проектами, структура тестового класу з атрибутами `[TestClass]`, `[TestMethod]` та базова реалізація перших перевірок за патерном AAA.

## ⏱ Детальний структурований конспект за темами та таймлайном
### `[00:00:00 - 00:06:00]` Вступ: що таке юніт-тестування та завдання на ЛР
- Ідея юніт-тестування: перевірка окремого виконуваного модуля або функції в автоматизованому режимі.
- У лабораторній роботі кожен студент бере функцію відповідно до свого варіанту (номер варіанту відповідає списку групи).
- Чому це важливо: автотести запускаються в один клік і гарантують збереження працездатності коду при подальших змінах.

### `[00:06:00 - 00:16:00]` Створення рішень та проектів у Visual Studio
- Створення основного проекту (Class Library або Console App на C#).
- Додавання тестового проекту: `Add -> New Project -> MSTest Test Project` (на C# це робиться без складних налаштувань лінкувальника, на відміну від C++).
- Додавання посилання на проект: `Dependencies -> Add Project Reference` -> ставимо галочку навпроти основного проекту.
- Підключення простору імен: `using MyProject;`.

### `[00:16:00 - 00:33:23]` Написання та структура юніт-тесту на C#
- Атрибут `[TestClass]` для класу тестів та `[TestMethod]` для кожного тестового методу.
- Шаблон побудови тесту AAA:
  1. **Arrange:** підготовка вхідних змінних та очікуваного значення.
  2. **Act:** виклик методу основної програми.
  3. **Assert:** звірка результатів через `Assert.AreEqual(expected, actual)`.
- Запуск тестів через вікно `Test Explorer`, аналіз зеленого кольору успішного проходження та червоного при невідповідності результатів.

## 💡 Важливі акценти, правила викладачки та типові помилки
- Викладачка окремо підкреслює, що на C# налаштувати юніт-тести значно швидше і простіше, ніж на C++.
- Кожен тестовий метод повинен мати змістовну назву, що пояснює суть перевірки (наприклад, `TestMethod_ValidInput_ReturnsExpected`).
