### `[00:01:31 - 00:10:00]` Вступ: ручне vs автоматизоване тестування

- Автоматизація не скасовує ручне тестування: ручний тестувальник пише сценарії та тест-кейси, а автоматизатор перетворює їх на код.
- Людський фактор: втома та замилювання очей при ручному багаторазовому тестуванні (приклад з випадковим натисканням 5 замість 3).

### `[00:10:00 - 00:20:00]` Коли автоматизація виправдана: регресія та ROI
- Автоматизація найбільш ефективна для повторюваних завдань — передусім регресійного тестування.
- Високонавантажені додатки, тестування продуктивності та кросплатформенність.
- Економічна доцільність (ROI): якщо тест виконується один раз, писати автотест недоцільно; якщо сценарій запускається після кожного білду — автоматизація окупається багаторазово.

### `[00:20:00 - 00:32:00]` Піраміда тестування (Test Pyramid)
- **Основа (База) — Unit Tests (Модульні тести):** швидкі, дешеві, виконуються за мілісекунди, ізольовані, пишуться девелоперами разом з QA. Складають левову частку всіх автотестів.
- **Середній рівень — Integration / API Tests:** перевірка взаємодії сервісів та бізнес-логіки.
- **Вершина — UI / End-to-End (E2E) Tests:** повільні, крихкі (fragile), дорогі в розробці та підтримці. Повинні покривати лише критичні бізнес-шляхи користувача.

### `[00:32:00 - 00:46:00]` Модульне тестування (Unit Testing) та концепція AAA
- Патерн побудови тесту **AAA (Arrange-Act-Assert):**
  * **Arrange (Підготовка):** ініціалізація змінних, об'єктів, підготовка тестових даних.
  * **Act (Дія):** виклик тестованого методу з отриманням фактичного результату.
  * **Assert (Перевірка):** звірка фактичного результату з очікуваним за допомогою методів Assert.
- Автономність та незалежність тестів один від одного.

### `[00:46:00 - 01:04:00]` Практика у Visual Studio на C# (MSTest)
- Створення проекту типу Unit Test Project у Visual Studio.
- Атрибути тестових класів та методів: `[TestClass]`, `[TestMethod]`.
- Методи тверджень: `Assert.AreEqual()`, `Assert.AreNotEqual()`, `Assert.IsTrue()`, `Assert.IsFalse()`.

## 📖 Глосарій ключових термінів та визначень лекції
- **Автоматизоване тестування (Test Automation):** Процес виконання тестів, контролю їхнього результату та фіксації звітів за допомогою спеціальних програмних засобів без прямої участі людини.
- **Піраміда тестування (Test Pyramid):** Архітектурна модель, що візуалізує рекомендоване співвідношення рівнів тестів: багато швидких Unit-тестів внизу, менше інтеграційних посередині, мінімум дорогих UI-тестів нагорі.
- **Шаблон AAA (Arrange-Act-Assert):** Стандартний патерн написання тестового методу: налаштування оточення, виконання дії, перевірка результату.
- **Assert (Ствердження):** Спеціальна функція або метод у тестовому фреймворку, що порівнює очікуване значення з фактичним і генерує виняток при їхній розбіжності.
- **Regression Testing Automation:** Автоматизація регулярного прогону перевірок для запобігання появі старих помилок у нових збірках програми.
